This is a train pack for Subway Builder which currently adds 275 new trains from across the world to Subway Builder using [addTrains](https://github.com/mhmoeller/subwaybuilder-addtrains/tree/V1.0-rc) by mhmoller. 

To install, simply download the folder and put it in the mods folder. Make sure to also install addTrains.
