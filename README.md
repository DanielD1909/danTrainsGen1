This is a train pack for Subway Builder which currently adds 275 new trains from across the world to Subway Builder using [addTrains](https://github.com/mhmoeller/subwaybuilder-addtrains/tree/V1.0-rc) by mhmoller. Lookup Spreadsheet can be found [here](https://docs.google.com/spreadsheets/d/1-MS_a7KJlQe3AjBkb6nC7ne4Dhnabtay2W16JrEzVyo/edit?usp=sharing)

To install, simply download the folder and put it in the mods folder. Make sure to also install addTrains.
